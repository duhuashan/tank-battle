## 3. 核心概念

### 3.1 继承：`class Enemy(Tank)`

```python
class Enemy(Tank):
    def __init__(self, x, y):
        super().__init__(x, y)                      # 先跑一遍父类的初始化
        self.direction = random.choice(DIR_NAMES)   # 初始朝向随机
        self.next_turn = 0                          # 下次换向的时间点（毫秒）
        self.next_shot = 0                          # 下次开火的时间点
```

`super().__init__(x, y)` 的意思是"**先把爸爸那一套初始化跑一遍**"，于是 `rect`、`speed`、`bullets`、`old_rect` 全都有了。你只补敌人特有的那几样。

（记得在文件顶部 `import random`。）

### 3.2 把 `Tank.move` 改成吃"方向字符串"

现在 `Tank.move(key)` 里是 4 段 `if/elif`，而 `DIR_VECTORS` 里**早就存着**"方向 → 位移"了 —— 同一件事写了两遍。改掉：

```python
def move(self, direction):
    self.old_rect = self.rect.copy()
    if direction is None:
        return
    self.direction = direction
    dx, dy = DIR_VECTORS[direction]
    self.rect.x += dx * self.speed
    self.rect.y += dy * self.speed
```

主循环那边**必须同步改**（改接口就要连带改调用点，这是第一课）：

```python
KEY_TO_DIR = {pygame.K_UP: "UP", pygame.K_DOWN: "DOWN",
              pygame.K_LEFT: "LEFT", pygame.K_RIGHT: "RIGHT"}
...
tank.move(KEY_TO_DIR.get(first_pressed_key))
```

> **备选（零改动）**：不动 `Tank`，在 `Enemy` 里覆盖 `move()` 自己写位移。省事，但位移逻辑被抄了第二遍，条目 14 拆模块时还得回来收拾。**建议按上面的改。**

### 3.3 敌人怎么"自己决定方向"：两个触发器**都要有**

- **定时器**：`pygame.time.get_ticks()` 超过 `self.next_turn` 就重抽一个方向（写法与条目 6 的 `last_shot` 冷却一模一样）。
- **撞墙就换**：这是"不卡死在墙角"的关键。`Tank.check_collision()` 撞墙时会把 `rect` 还原，于是你可以用"位置有没有被改回去"来判断刚刚撞了墙：

```python
def check_collision(self):
    moved = self.rect.copy()
    super().check_collision()      # 撞墙 → 回退
    if self.rect != moved:         # 被回退了 ⇒ 刚才撞墙了
        self.turn()
```

只做定时器会怎样？敌人可能贴着墙连撞十几帧（每帧原地回退），看起来就是"卡死在墙角" —— 正是完成标志要枪毙的现象。

### 3.4 敌人开火：复用同一个 `Bullet`

```python
if ticks >= self.next_shot:
    self.bullets.append(Bullet(self.rect, self.direction))
    self.next_shot = ticks + random.randint(800, 2500)    # 毫秒
```

再让 `turn()` 里把 `next_shot` 也重抽一次：方向一换就重新计时，免得"刚转身就开火打墙"。

### 3.5 主循环改成"玩家 + 敌人列表"

```python
enemies = [Enemy(40, 40), Enemy(720, 40), Enemy(40, 520)]   # 三个空格位置

for e in enemies:            # 更新
    e.move(e.direction)
    e.check_collision()
    e.clamp_position(screen_rect)
    e.update_bullets()

for e in enemies:            # 绘制
    e.draw(screen)
    e.draw_bullet(screen)
```

玩家那一侧的逻辑**一个字都不用动**。

**出生坐标**（这四个都是 `MAP_DATA` 里的空格，不会一出生就撞墙）：`(40, 40)`、`(720, 40)`、`(40, 520)`、`(720, 520)` —— 挑 3 个。玩家出生点在 `(360, 280)`，离得开。

## 6. 踩过就懂的坑

1. **把 `next_shot` / `next_turn` 写在 `class Enemy:` 的类体里** → 那是**类属性**，3 个敌人共用一个计时器，只有一辆在开火。**必须写在 `__init__` 里**（实例属性）。
2. **只做定时换向、不做"撞墙即换向"** → 贴墙时每帧原地回退，视觉上就是卡死。两个触发器都要有。
3. **每帧都 `random.choice` 抽方向** → 坦克原地抽风、几乎不移动。必须用计时器控制"多久抽一次"。
4. **敌人生成在墙格里** → 一出生就被判定撞墙，永远动不了。出生坐标必须落在 `MAP_DATA` 为 `0` 的格子上（第 3.5 节给的那四个就是）。
5. **忘了给敌人调 `clamp_position`** → 敌人可能跑出屏幕（多数情况会被边界墙挡住，但别依赖巧合）。
6. **改了 `Tank.move` 的签名却忘了改主循环里的调用** → `pygame.K_UP` 是个大整数，拿它去查 `DIR_VECTORS` 会直接 `KeyError`。**"改接口要连带改所有调用点"**，这是本条最值钱的一课。
7. **敌人子弹和玩家子弹想混进同一个列表** → 条目 11 要判断"谁打中了谁"时会很痛。让每个坦克持有自己的 `bullets`（继承 `Tank` 天然就是这样），别急着合并。
8. **用 `random.random() < 0.01` 这种"每帧碰运气"控制换向/开火** → 帧率一变频率就变，行为不可复现，探针也测不稳。用**时间戳 + 随机间隔**。
