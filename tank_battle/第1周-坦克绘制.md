## 3. 绘制思路（自己写，本文不给成品代码）

### 3.1 车体

保持现在的 40×40 矩形即可（想加两条深色履带让坦克更好认，也可以 —— 属于加分项，不影响验收）。

### 3.2 炮管的几何

炮管 = 一根**细长矩形**，从**车体中心**朝当前方向伸出去。关键几何：

- **尺寸随方向旋转**：
  - 朝左/右（水平）：`宽 = 炮管长度`、`高 = 炮管粗细`
  - 朝上/下（垂直）：`宽 = 炮管粗细`、`高 = 炮管长度`

  （长度建议 **20**，粗细建议 **8** —— 车体 40×40，炮管伸出半个车身，比例最清楚。）

- **定位用 `centerx / centery`，别手算 `x / y`**：
  炮管的**内端**要落在车体中心，所以从 `self.rect.centerx`、`self.rect.centery` 出发最稳 ——
  这两个属性是**只读即得的中心点**，不用自己算 `x + w/2`。

  > （`centerx`/`centery` 是 `Rect` 的属性；给矩形对象设置 `centerx=…` 会自动换算 `x`。
  > 你可以用 `pygame.Rect(0, 0, w, h)` 建一个，再设它的 `centerx/centery`，最后 `pygame.draw.rect` 画出来。）

- **四个方向 = 四个分支**：`if/elif` 四选一最直观；
  也可以用一个字典把「方向 → (尺寸, 偏移)」映射起来（更短，但可读性自己权衡）。
  **选哪个是你自己的设计决定**，说得出理由就行。

### 3.3 画的顺序

`draw()` 里：**先画车体，再画炮管**（后画的盖在上面）。炮管颜色建议和车体**不同**（比如车体绿、炮管浅黄或白），这样一眼能分辨。

### 3.4 可选：让车体本身也更好认

- 加两条深色"履带"（车体左右或上下各一条细矩形）—— 但要注意**履带也随朝向变化**，否则朝左和朝右看不出区别。
- 这一步是加分项，验收不强制。

## 4. 建议的实现顺序

1. **先只加一根固定朝上的炮管**（不管 `direction`）：确认它从**车体中心**伸出、长度粗细合适。
   跑一下 —— 看到一根"天线"从中间戳出来就对了。
2. **让炮管跟随 `self.direction`**：四个分支，四个朝向各画一次。
3. **移动中检查**：按方向键边走边看，朝向是否**立刻跟着变**（不是松手才变）。
4. **自测四方向**：上、下、左、右各按一次，截图或肉眼确认炮管位置**互不相同**。
5. （可选）加履带 / 换配色。

## 5. 验收标准（逐条打勾）

| # | 验收项 | 怎么验 | 期望结果 |
|---|---|---|---|
| 1 | 有车体 | `python main.py` | 屏幕上有坦克（不只是炮管） |
| 2 | **四个朝向炮管各不相同** | 上/下/左/右各按一次 | 每个朝向炮管伸出的方向**明显不同** —— **这是需求文档唯一的硬指标** |
| 3 | 炮管从中心伸出 | 看炮管根部 | 从车体**中间**伸出，不是从某个角 |
| 4 | 朝向随移动即时更新 | 按方向键边走边看 | 一按就转向（不是松手后才转） |
| 5 | 静止时保持最后朝向 | 走一段后松手 | 保持松手前的朝向，**不会**弹回初始的 `"UP"` |
| 6 | 炮管可伸出屏幕（已知行为） | 把坦克顶到边界 | 车体在界内即可，炮管伸出去一点**是允许的** —— 你只要知道这是预期行为 |
| 7 | 帧率稳定 | 探针 / `clock.get_fps()` | 稳态仍在 60 附近（现在每帧画 2~3 个矩形，影响可忽略） |

| 9 | 已提交 | `git log --oneline` | 新增 commit，信息形如 `feat: 坦克绘制加入车体与随朝向变化的炮管` |

## 6. 常见坑（按踩中概率排序）

1. **⚠️ 大小写不一致**：你的 `direction` 是**大写** `"UP"`，如果这里写成 `if self.direction == "up"`，
   **永远不会匹配，且没有任何报错** —— 表现为炮管一直不变（或根本不画）。保持 `"UP"`/`"DOWN"`/`"LEFT"`/`"RIGHT"`。
2. **炮管在 `__init__` 里算好存起来** → 坦克移动时炮管**不跟随**（位置是旧的）。
   **必须在 `draw()` 里每帧重算**（或至少每帧更新位置）。
3. **从角落伸出**：用 `self.rect.x + 40` 之类硬编码偏移，炮管会从车体边缘甚至外面长出来。
   用 `centerx / centery` 定位最稳。
4. **忘了四选一的某一支**：比如只写了上下、漏了左右 —— 按左/右键时炮管不动。四个都要测。
5. **炮管太长**（比如 60）→ 看起来像根棍子；**太短**（比如 5）→ 看不出朝向。20 左右最清楚。
6. **炮管和车体同色** → 视觉上糊成一团，验收第 2 条自己都看不清。换一个明显不同的颜色。
7. **画完炮管忘了画车体**（或顺序颠倒被盖住）→ 只剩一根棍子在动。
8. 想加履带但**履带不随朝向变** → 朝左和朝右看起来一样，验收第 2 条会挂。
